## The reading

- **Unattended, on judgement, as Phase Q was** — but Jesse's standing rules still hold: rules are his to
  call, numbers live in the sheet, the goldens move only in named commits, small commits in the imperative,
  one change a commit, and anything that touches play is revertible on its own.
- **So the weight goes where nobody has made a call yet: how the game feels.** Six phases of measurement
  have gone into the rules; none into the fact that the game was silent, or that a player could not find
  their own dog in a race. Those are things a player notices in the first minute.
- **Play it first.** Drive a solo game in a real browser at 1280 and 390, screen by screen, and fix what is
  actually wrong rather than what a document says might be.
- **One rules-adjacent change is fair game:** GDD_V3 §14 Q15 says outright that "an AI phase could teach
  Normal to read" the Race Office. An AI change is not a rule, but it moves the goldens and every harness
  row that six Normal stables produce, so it is measured, revertible, and a §13 row for Jesse to keep or
  revert — the Q-row pattern.
- **Do not end live rooms.** No `STATE_VERSION` or `PROTOCOL_VERSION` move unless a rule moves, which
  this reading does not plan for; a push of this phase should be safe on any evening.
- Hand back the way Phase Q did: a clone in the container, a bundle into the folder, a fast-forward if
  git in the folder allows it, and the commands if not.
